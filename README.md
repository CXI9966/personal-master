# Butler

个人管家桌面客户端（Windows）。每天打卡、排计划、管任务、做复盘，日历像 GitHub 那样按每天的记录深浅着色；接上一个大模型接口，还有一个会说话、能帮你改计划的“管家”。不依赖任何特定的 AI 产品，填上接口地址、模型名和 API key 就能用。

所有数据都放在你自己选的一个文件夹里（工作区），程序坏了、卸载了，数据也还在。

## 安装

1. 运行 `Butler-Setup-0.1.0.exe`（见 `npm run dist` 的输出目录 `release/`）。
2. 安装包没有签名，Windows 可能提示“未知发布者”：点“更多信息 → 仍要运行”。
3. 默认装在当前用户的目录下，不需要管理员权限；安装时可以改位置。
4. 卸载：Windows 设置 → 应用。**卸载只删程序，你的工作区文件夹不会动。**

第一次运行会问三件事：工作区放哪个文件夹、管家用哪种风格（战友教练 / 温和陪伴 / 严格教官，之后都能改）、模型接口（可以先跳过）。

## 配置管家的模型

设置页 → “管家的模型接口”：

- **接口类型**：OpenAI 兼容，或 Anthropic。
- **接口地址**：原样填，程序不会替你补 `/v1`。OpenAI 兼容的一般以 `/v1` 结尾。
- **模型名**、**API key**。点“测试连接”，通过再保存。
- API key 用 Windows 的加密功能保存在应用数据目录，**不会写进工作区**，也不会出现在任何同步或备份的文件里。
- 模型不支持工具调用时，把“动作模式”改成“JSON 文本”。
- 管家看到多少内容有三档：按场景挑（默认）、全部、让它自己按需查。用量在设置页的“本周用量”里，只显示，不设上限。

管家的小改动（加任务、改精力、排时间）直接生效，卡片上有“撤销”；重排整天、删任务、批量改期这类大改动要你点确认才会执行。

## 数据在哪

工作区文件夹里：

| 位置 | 是什么 | 能不能手改 |
| --- | --- | --- |
| `data/` | 程序读写的原始数据（JSON / JSONL）：打卡、任务、计划、体重、设置…… | 不建议，改坏了界面会提示 |
| `今日.md` `本周.md` `我的设定.md` `记录/` `任务库/` `归档/` | 程序根据 `data/` 自动生成、给人看的文字版，每周还有 `周报.md` | 不要改，下次会被覆盖 |
| `管家人格.md` | 管家的说话方式和规矩，四个小节 | 可以，设置页里也能改 |
| `课表.md` | 你自己写的课表 | 可以 |

应用自己的设置（上次打开的工作区、加密的 API key、提醒记账）在 `%APPDATA%\butler`。

## 改错了怎么办

- 每次改动（打卡、勾任务、复盘、管家改的……）之后，窗口顶部都有“撤销”。最近 50 次改动改之前的样子保存在 `data/.history`。
- 数据文件被改坏时，界面顶部会提示，并给“恢复上一个版本”。
- 想整个回到某一天：工作区就是普通文件夹，直接复制备份就行。程序不会自动备份。

## 周报、提醒和开机自启

- **周报**：每周结束后，记录页里出现那一周的小结（只说做到的），同时生成 `归档/<年>/<年-Www>/周报.md`。点“让管家点评”才会调用模型。
- **提醒**（设置页，默认关）：设一个时间，到点还没排计划 / 没复盘，就弹一条 Windows 通知，每件事每天最多一次。关掉窗口后程序留在托盘里，提醒才会继续；托盘右键可以退出。
- **开机自启**（设置页，只有装好的版本有这个开关）：开机后只留在托盘，不弹窗口。

## 开发

需要 Node.js 24 以上。

```
npm install
npm run dev          # 开发模式
npm run typecheck
npm run dist         # 在 release/ 下生成安装包
```

- 国内网络下载 Electron、打包工具慢或失败时：`npm install` 用的 Electron 镜像已经写在 `package.json` 的 `config` 里；打包前再设置环境变量 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`。
- 图标是程序自己画的（`src/main/app/icon.ts`），改完后 `npm run icon` 重新生成 `build/icon.png`。
- 设计和实施计划在 `docs/superpowers/`。
